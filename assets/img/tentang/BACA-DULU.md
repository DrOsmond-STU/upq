# Foto kolase "Tentang UPQ" di beranda

4 ubin foto pada bagian "Tentang UPQ" di beranda. Taruh file `.jpg` dengan
nama berikut:

| Nama file                 | Ubin |
|----------------------------|------|
| `area-produksi.jpg`        | Area Produksi |
| `ruang-kunjungan.jpg`      | Ruang Kunjungan |
| `kunjungan-pelajar.jpg`    | Kunjungan Pelajar |
| `tashih-mushaf.jpg`        | Tashih Mushaf |

Rasio persegi (1:1), minimal 600×600px. Selama file belum ada, ubin memakai
ilustrasi ikon sebagai pengganti. Untuk mengubah daftar/urutan ubin, edit
array `tentangPhotos` di `index.html`.
