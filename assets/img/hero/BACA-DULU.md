# Foto slide beranda (hero)

Taruh foto di folder ini dengan nama file PERSIS seperti berikut (format `.jpg`):

| Nama file      | Dipakai untuk slide ke- |
|----------------|--------------------------|
| `slide-1.jpg`  | 1 |
| `slide-2.jpg`  | 2 |
| `slide-3.jpg`  | 3 |
| `slide-4.jpg`  | 4 |

**Rekomendasi:** foto landscape/mendatar, minimal 1600×900px, orientasi lebar
(bukan potret), berat file idealnya di bawah 500KB (kompres dulu supaya
halaman tetap ringan).

Selama file belum ada, slide otomatis memakai gradasi hijau polos sebagai
pengganti — jadi aman diupload satu per satu, tidak perlu menunggu keempatnya
lengkap.

Ingin menambah atau mengurangi jumlah slide? Ubah array `HERO_SLIDES` di
`assets/js/data.js`.
